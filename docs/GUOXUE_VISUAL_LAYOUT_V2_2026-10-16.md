# 国学画风与版式 V2：古典工笔淡墨、4:3主体

## 用户最新要求

按用户提供的古代文士读卷参考图制定风格，主体图片改为4:3；竖版其余空间使用同图模糊背景填充。此前指定主标题、副标题、字幕和脚注继续保留，内容先用占位样例。

## 画风与提示词

- 米灰、暖米白宣纸底；人物细墨线，松树苍劲墨笔，远山淡墨层染。
- 灰褐、墨黑、米白为主，青绿与灰蓝少量点缀，低饱和淡彩。
- 古代素袍文士、束发髻、卷轴、笔砚、松竹与水榭庭院；取代 V1 近现代碎花布衣语境，取消对古代宽袖与发髻的禁止。
- 场景按文案含义变化；现代生活问题可作哲理视觉演绎，不编造历史事件，不混入现代物件。
- 沿用4K档3×3九宫格，整图和每格均为4:3，首格独立封面、其余正文分镜。实际像素尺寸需返回后校验；4K档不等于单格原生4K。
- 参考图用于本地版式与风格定义；当前供应商调用仍为文字提示词，未实现参考图条件输入，也尚未生成 V2 新图验证相似度。

## 合成布局

- 成片1080×1920；清晰主体1080×810，水平居中、顶部 y=555。
- 主体完整等比保留；上下背景取同图放大裁切，模糊 sigma=36，轻微降低亮度。
- 主体不使用放大运镜，避免裁切人物、手部和卷轴，减少细线闪动。
- 主副标题仍在顶部；字幕中心 y=1280；脚注保持视频右下角。
- 锐气楷尚未安装，本机暂用 KaiTi。继续支持 `RENDER_TITLE_FONT_FILE` 配置字体文件。
- 封面和正文使用同一合成逻辑，按实际图片4:3比例识别；现有竖图继续原渲染方式。
