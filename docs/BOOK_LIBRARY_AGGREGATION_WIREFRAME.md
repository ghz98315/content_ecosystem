## 1. 页面职责

书籍库是聚合视图，不负责逐条采集数据操作。

- 以书籍为单位聚合任务、运行状态、异常和视频产物。
- 点击书籍卡片打开右侧聚合抽屉。
- 从抽屉可以筛选该书籍的全部任务，或打开最近任务。
- 逐条运营数据仍在“视频采集工作台”中查看。

## 3. 顶部区域

### 3.1 页面标题

```text
BOOK LIBRARY
书籍库
按逐字稿识别结果聚合书籍、任务和成片
```

标题区域不做营销式大 Hero，保持紧凑，首屏必须同时看到统计卡和第一排书籍卡片。

### 3.2 页面操作

```text
[刷新数据] [新增书籍]
```

- 刷新数据：重新加载聚合统计，不修改任务。
- 新增书籍：仅用于人工创建没有采集任务的书籍资料。
- 从逐字稿识别出的书籍自动进入书籍库，无需手动新增。

### 3.3 搜索和排序

```text
[搜索书名或作者____________________] [全部书籍状态 ▼] [最近更新 ▼]
```

书籍状态筛选：

- 全部。
- 已确认。
- 待确认。
- 人工创建。
- 未关联任务。

排序：

- 最近更新。
- 任务最多。
- 视频最多。
- 异常优先。
- 书名顺序。

## 4. 顶部统计卡

保持参考图中的四项统计，不增加过多卡片。

```text
┌────────────────────┐ ┌────────────────────┐ ┌────────────────────┐ ┌────────────────────┐
│ 书籍数             │ │ 任务总数           │ │ 运行中             │ │ 视频产物           │
│ 9                  │ │ 25                 │ │ 5                  │ │ 45                 │
│ 已确认7 / 待确认2  │ │ 全部历史任务       │ │ 待确认2 / 异常1    │ │ 可下载和二创       │
└────────────────────┘ └────────────────────┘ └────────────────────┘ └────────────────────┘
```

统计口径：

- 书籍数：已识别、人工创建和待确认书籍总数；明确标记“无书籍”的任务不计入。
- 任务总数：已关联到书籍的任务总数。
- 运行中：状态为处理中任务的数量。
- 视频产物：成功生成并保留的成片文件数量，不等同于已完成任务数。

## 5. 书籍卡片

卡片为三列布局，信息结构固定，所有卡片保持相同高度。

```text
┌──────────────────────────────────────────────┐
│ ┌────────┐  《身体重置》             ● 已确认│
│ │        │  作者：某某                        │
│ │ 封面   │  国籍：美国                        │
│ │        │                                    │
│ └────────┘                                    │
│                                              │
│ [4个任务] [3个完成] [1个运行] [0个异常]      │
│ [4个视频]                                    │
│                                              │
│ 最近更新：08-10 20:18                       │
│                                              │
│ [筛选任务] [打开最近任务]                 [⋯]│
└──────────────────────────────────────────────┘
```

### 5.1 卡片字段

| 字段 | 规则 |
| --- | --- |
| 封面 | 使用人工上传封面；没有封面时使用统一占位，不随机生成 |
| 书名 | 最多两行，始终使用书名号 `《》` |
| 作者 | 独立显示 |
| 国籍 | 有数据时显示，无数据不占空行 |
| 书籍状态 | 已确认、待确认、人工创建 |
| 任务数 | 当前书籍关联任务总数 |
| 完成数 | 已完成任务数 |
| 运行数 | 处理中任务数 |
| 异常数 | 失败任务数 |
| 视频数 | 已生成成片产物数 |
| 最近更新 | 该书籍下最近任务或书籍信息的更新时间 |

### 5.2 卡片主操作

- `筛选任务`：进入视频采集工作台，并自动选中当前书籍。
- `打开最近任务`：进入该书籍最近更新的一条任务。
- 待确认书籍将第一按钮替换为 `确认书籍`。
- 点击卡片非按钮区域：打开右侧书籍聚合抽屉。

### 5.3 更多菜单

```text
编辑书籍信息
更换封面
新建同书任务
复制书籍信息
查看全部成片
```

不提供直接删除书籍。删除前必须处理关联任务和成片，避免产生孤立数据。

### 7.1 抽屉头部

- 封面、书名、作者、国籍。
- 已确认、待确认、已修正或人工创建状态。
- 识别来源、置信度。
- 编辑书籍信息和更换封面。

低置信度书籍在头部直接显示 `确认书籍信息` 主按钮。

### 7.2 抽屉统计

- 任务总数。
- 完成数。
- 运行数。
- 待确认数。
- 异常数。
- 视频产物数。

统计数字可点击，点击后过滤抽屉中的任务列表。

### 7.3 抽屉任务列表

每项展示：

- 视频标题。
- 原视频作者和时长。
- 创建或最近更新时间。
- 当前阶段和八阶段进度。
- 最新成片状态。
- 与采集表格一致的状态主操作。

抽屉默认只加载最近 10 条，避免书籍任务过多导致首屏迟缓。

### 7.4 抽屉底部操作

- `筛选全部任务`：跳转到采集页，并带入当前书籍筛选。
- `打开最近任务`：打开最近更新的一条任务。
- `新建同书任务`：新任务预填当前书籍信息和封面引用。

## 8. 待确认书籍抽屉状态

当书籍处于待确认状态时，抽屉头部切换为确认模式。

```text
┌──────────────────────────────────────┐
│ 确认书籍信息                      × │
├──────────────────────────────────────┤
│ 识别依据                             │
│ “在《身体重置》这本书中……”         │
│                                      │
│ 候选                                 │
│ ○《身体重置》 68%                   │
│ ○《重启身体》 21%                   │
│                                      │
│ 书名 [身体重置____________________] │
│ 作者 [某某________________________] │
│ 国籍 [美国________________________] │
│                                      │
│ [上传封面]                           │
│ □ 本条内容没有明确书籍               │
│                                      │
│                [取消] [确认并保存]  │
└──────────────────────────────────────┘
```

确认后：

- 更新所有使用同一识别书籍 ID 的聚合关系。
- 人工结果优先于后续模型输出。
- 后续书籍阶段读取确认结果，不重新覆盖。
- 封面只使用人工上传或已有受控封面。

## 9. 空状态与异常状态

### 9.1 没有书籍

```text
还没有识别到书籍
逐字稿完成后，识别出的书籍会自动进入这里。
[前往视频采集]
```

### 9.2 搜索无结果

```text
没有匹配的书籍
尝试清空搜索或切换书籍状态。
[重置筛选]
```

### 9.3 聚合加载失败

```text
书籍数据加载失败
任务数据没有被修改，可以重新加载。
[重新加载]
```

### 9.4 封面加载失败

- 卡片结构和文字不能跳动。
- 使用固定比例占位图。
- 提供“重新加载封面”，不影响任务统计。

## 11. 数据聚合口径

```text
book_id
  ├── 书名、作者、国籍、封面
  ├── 识别状态、置信度、人工覆盖
  └── tasks[]
       ├── total
       ├── done
       ├── processing
       ├── needs_review
       ├── failed
       └── video_artifacts
```

实现时不能只按书名字符串聚合，否则同名书籍、错别字和人工修正会产生重复卡片。需要稳定的 `book_id` 或等效聚合标识。

## 13. 抽屉交互细化（开发交付口径）

### 13.1 打开、关闭与返回

- 点击书籍卡片主体、书名或统计数字，打开同一书籍的右侧抽屉；点击卡片按钮只执行按钮动作，不同时打开抽屉。
- 抽屉打开时保留列表滚动位置，关闭后恢复原位置；浏览器后退键优先关闭抽屉，再执行页面返回。
- 抽屉打开期间，背景列表保持可见但不可操作，使用半透明遮罩；点击遮罩只关闭抽屉，不触发列表动作。
- 手机端抽屉为全屏页面层，顶部必须提供返回按钮和书名，不能依赖从屏幕边缘滑动返回。

### 13.2 任务筛选与分页

```text
[全部 4] [处理中 1] [待确认 0] [失败 0] [已完成 3]
[搜索任务标题________________] [最近更新 ▼]
```

- 状态数字来自同一聚合查询，切换筛选只更新任务列表，不重新加载书籍头部。
- 默认按最近更新时间倒序；搜索只匹配标题、原作者和任务 ID。
- 首次加载 10 条，滚动到底部再加载下一页；加载中显示列表骨架，不清空已有结果。
- 过滤后无结果显示“该状态暂无任务”和“清除筛选”，不能显示空白抽屉。
- 抽屉内的任务操作完成后，只刷新该任务行及头部统计，避免整页闪烁。

### 13.3 任务行操作优先级

每行只保留一个主按钮，主按钮由状态决定：

| 状态 | 主按钮 | 允许的次操作 |
| --- | --- | --- |
| 待确认 | 确认书籍 | 查看任务、查看识别依据 |
| 处理中 | 查看当前阶段 | 查看任务、停止；心跳过期时增加从断点继续 |
| 失败 | 查看错误 | 从失败阶段恢复、查看旧产物 |
| 已完成 | 查看成片 | 查看质检、下载、爆款二创 |
| 已取消 | 查看记录 | 复制为新任务 |

- “从失败阶段恢复”必须带阶段名，例如“从生图阶段恢复”，禁止使用无上下文的“重启”。
- “从断点继续”仅在 Worker 心跳超时且后端确认存在可恢复断点时显示。
- 下载、爆款二创等产物动作只能对真实存在的 artifact 显示；没有产物时不展示假按钮。

### 13.4 书籍信息编辑边界

- 编辑书名、作者、国籍和封面后，先保存书籍实体，再刷新关联任务的展示字段；不重新触发逐字稿或改写。
- 手工修正字段记录 `source=manual` 和修改时间，后续识别任务不得覆盖手工值。
- 更换封面只影响书籍卡片、抽屉和新建同书任务的默认封面，不修改历史成片中的图片。

### 13.5 加载、错误与可访问性

- 首次打开显示头部骨架、统计骨架和三行任务骨架，抽屉宽度与最终内容一致，避免布局跳动。
- 聚合接口失败时保留书籍基本信息，并在任务列表位置显示重试条；重试不丢失当前筛选。
- 抽屉拥有明确的标题语义和 `aria-label`，打开后焦点进入关闭按钮，关闭后焦点回到触发卡片。
