# 图片生成工作台 ASCII 线框图

> 状态：细化规划稿
>
> 参考：`ref-doc/05.png`，并以当前九宫格生成、3x3 切图和 4:3 分镜产物为实际边界。
>
> 本文只确认页面结构、字段和交互，不修改网页代码、数据库或 Worker。

## 1. 页面定位

图片生成页需要同时解决四件事：

1. 一眼看清整条任务需要多少分镜、已生成多少、缺失多少。
2. 高密度浏览所有分镜，不逐张点开才能判断整体风格。
3. 明确每张图与字幕、提示词、时间轴和九宫格来源的对应关系。
4. 允许未来对违规或不合适的单张图片局部重生成，不重复整批计费。

页面采用“统计与筛选 + 高密度图片网格 + 单图检查抽屉”，而不是只展示图片缩略图。

## 3. 顶部摘要信息

| 摘要 | 数据口径 |
| --- | --- |
| 分镜总数 | 当前最终文案切出的 storyboard 数量 |
| 已生成 | 已存在且可读取的切图产物数量 |
| 九宫格批次 | 按 9 个分镜一批计算，并显示真实 source grid 数量 |
| 缺失 | 应有分镜减去有效图片产物 |
| 预计画面时长 | 所有分镜 `estimated_duration` 之和；TTS 完成后显示真实时间轴时长 |
| 当前状态 | 待生成、生成中、部分完成、待人工检查、已就绪、失败 |

“63/63 已生成”不等于全部质量合格；必须把“产物完整”和“人工检查结果”分开显示。

## 4. 模式与风格信息

当前正式规则固定显示为可阅读摘要：

```text
生成模式：3x3 九宫格批量生成
单图比例：4:3
切分策略：每批最多 9 个分镜，整张大图生成后按九宫格切分
视觉方向：生活化写实、轻微油画质感、人物不过度真实
受众方向：适合中老年审美，温暖、清晰、低刺激
文字规则：画面内禁止可见文字；书名封面使用人工上传参考图
健康规则：违规医学场景替换为生活化类比，不使用卡通化规避
```

- 这些规则默认折叠为一行摘要，点击后在抽屉查看完整配置，避免占用图片区首屏。
- 不允许用户在已经生成一半时随意改变全局风格；修改后应建立新图片版本。

## 5. 筛选与浏览工具

- 状态筛选：全部、已生成、生成中、失败、需人工检查、已替换。
- 批次筛选：全部批次或指定九宫格批次。
- 搜索：匹配字幕片段、分镜序号和提示词摘要。
- 查看密度：紧凑、标准两档；紧凑模式仍必须显示序号和状态。
- 排序固定以时间轴顺序为主，可临时切换“异常优先”，但不能改变最终成片顺序。
- 提供“只看缺失”和“只看违规替代”快捷筛选。

## 6. 分镜卡片信息

用户不打开详情时，每张卡至少能看到：

| 信息 | 当前来源 |
| --- | --- |
| 分镜序号 | `index` |
| 图片 | `path` 签名 URL |
| 对应字幕 | `sentence` |
| 字符区间 | `char_start` / `char_end` |
| 字数 | `char_count` |
| 预计时长 | `estimated_duration` |
| 动效 | `motion`，当前通常为 Zoom In |
| 九宫格来源 | `source_grid` 和批次号 |
| 比例 | 当前固定 4:3 |
| 状态 | 产物读取、生成任务和人工检查状态 |

字幕默认显示两行，悬停或展开可以阅读全文；长字幕不能把所有卡片高度撑乱。

### 抽屉内需要补充保存的数据

当前索引还没有完整保存以下字段，实现相关功能前需要补充：

- 实际提交给 Provider 的安全提示词。
- 原始语义到生活化类比的替换记录。
- Provider task ID、模型名、生成时间和重试次数。
- 人工检查状态、问题类型和替换原因。
- 单图版本号、当前采用版本和历史版本。

在这些数据和单图任务接口完成前，不显示可点击的“单独重新生成”按钮。

## 8. 九宫格批次视图

除切图网格外，支持切换“九宫格来源”视图：

```text
批次 01   Provider 已完成 · 9/9 已切分 · 4096x4096 · 校验通过
[原始九宫格大图]
[格1] [格2] [格3]
[格4] [格5] [格6]
[格7] [格8] [格9]
[查看提示词] [重新切分] [仅重跑失败格]
```

- “重新切分”复用已有九宫格源文件，不请求 Provider，不产生新的生图费用。
- 原始九宫格缺失或损坏时才允许重新请求整个批次。
- 后续仍统一使用九宫格，不切换为多张独立生成模式。

## 9. 失败与恢复

```text
Provider 请求超时但已有 task ID  → 继续轮询原任务，不重复提交
九宫格已生成、部分切图缺失       → 从原九宫格重新切分
单张画面质量不合格               → 编辑该分镜提示词后局部生成替代版本
整批提示词违规                   → 展示命中原因，生成生活化类比提示词后重试
图片签名 URL 失效                → 重新获取 URL，不重跑生图
```

- 不提供无含义的“全部重启”。
- 顶部主操作根据故障类型显示“继续等待 Provider”“重新切分”或“重跑失败批次”。
- 已成功的九宫格和切图必须保留，避免 32 次或更多重复生图。

## 10. 响应式与信息密度

- 宽屏 `>=1440px`：5-6 列 4:3 卡片，信息抽屉宽 480-560px。
- 桌面 `1024-1439px`：4 列。
- 平板 `768-1023px`：2-3 列，筛选工具分两行。
- 手机 `<768px`：2 列缩略图；点击后进入全屏详情，字幕和提示词在详情中阅读。
- 图片卡片使用稳定 `aspect-ratio`，图片加载、状态变化和按钮悬停不能改变网格尺寸。
- 首屏优先展示图片、序号、状态和字幕；Provider 技术信息放入抽屉，做到信息丰富而不拥挤。

## 11. 本页验收口径

1. 能看清总分镜数、生成数、缺失数、九宫格批次和任务状态。
2. 每张图能对应到字幕、字符区间、预计时长和九宫格来源。
3. 能查看原九宫格并区分“重新切分”和“重新生图”。
4. 违规画面可查看生活化类比提示词和替换记录。
5. 单图重生成只影响当前分镜，不重复已成功批次。
6. 人物保持轻油画感、不过度真实，避免卡通化和医疗红线场景。
7. 页面在高信息密度下仍能快速筛选、定位和放大检查。

## 12. 生图 Provider 主备通道策略

生产环境建议配置至少一个备用生图通道，但切换必须遵循幂等和批次一致性：

```text
主通道提交
    ├── 返回 Provider task ID ──> 持久化 ID，继续轮询原任务
    ├── 明确未提交               ──> 允许切换备用通道
    └── 明确失败且不可恢复       ──> 允许人工确认后切换备用通道
```

- 主通道和备用通道都必须实现统一的 `submit / poll / download / error` 接口。
- 每个九宫格批次保存 Provider 名称、task ID、提示词摘要、模型和提交时间。
- 超时不能直接再次提交；先用原 task ID 查询，避免重复计费。
- 同一任务切换备用通道后，后续批次尽量固定使用备用通道，避免同一条成片风格漂移。
- 备用通道切换需要记录原因，并在任务页显示“批次 3 使用备用通道”。
- 备用通道的画幅、九宫格比例、无文字安全规则和下载格式必须通过独立冒烟验证后才能启用。
- 不建议无条件自动主备切换；默认采用“自动等待原任务 + 人工确认切换”，稳定后再按错误类型开放自动切换。
