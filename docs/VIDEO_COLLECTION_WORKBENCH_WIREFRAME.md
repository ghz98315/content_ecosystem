# 视频采集工作台 ASCII 线框图

> 状态：待确认

## 1. 页面定位

“视频采集”作为独立工作台页面，与“内容项目库”并列。

- 内容项目库：按书籍和项目查看整体生产进度。
- 视频采集：批量导入视频、筛选采集结果、查看详细数据、执行批量任务。
- 任务详情：继续使用现有八阶段工作台，不在采集页重复建设详情页面。

## 2. 书籍识别节点

书籍第一次识别不等待后面的“书籍信息”阶段，而是在逐字稿生成完成后立即执行。

```text
URL 导入
   │
   ▼
视频采集
   │
   ▼
逐字稿生成
   │
   ├── 逐字稿未完成 ──────────────> 书籍状态：待识别
   │
   ▼
从逐字稿识别书名、作者、国籍和引用依据
   │
   ├── 高置信度 ──────────────────> 书籍状态：已识别
   ├── 低置信度或多候选 ──────────> 书籍状态：待确认
   └── 没有明确书籍 ──────────────> 书籍状态：未识别，可人工补充
   │
   ▼
后续“书籍信息”阶段
   │
   └── 人工修正、上传封面、编辑 CTA、最终确认
```

逐字稿完成后，采集列表立即可以按书籍筛选和聚合。

第一版导入规则：

- 一行一个 URL。
- 支持直接粘贴包含 URL 的分享文本。
- 自动去除同一次输入中的重复链接。
- 对数据库中已存在的 URL 给出明确提示，不重复创建。
- 创建成功后，新任务立即出现在下方列表顶部。

### 7.1 表格列说明

| 列 | 显示内容 |
| --- | --- |
| 选择 | 单选、全选和批量操作范围 |
| 序号 | 当前筛选结果中的顺序 |
| 视频内容 | 标题、描述摘要、关键词、来源链接 |
| 识别书籍 | 书名、作者、置信度、识别状态 |

| 操作 | 查看、确认书籍、补充书籍、处理异常 |

### 7.2 表格交互

- 表头固定，列表内容独立纵向滚动。
- 标题和描述最多显示两行，悬停或展开后查看全文。
- 点击整行进入现有任务详情页。
- 点击书籍状态打开书籍确认抽屉，不离开列表。
- 默认按采集时间倒序，新创建任务出现在顶部。
- 桌面端表格允许横向滚动，但核心列“视频内容、书籍、任务状态”优先固定。

## 8. 书籍识别状态

```text
┌────────────┬──────────────────────────────────────────────┬──────────────────────────────┐
│ 状态       │ 条件                                         │ 用户操作                     │
├────────────┼──────────────────────────────────────────────┼──────────────────────────────┤
│ 待识别     │ 逐字稿尚未完成                               │ 等待，无需操作               │
│ 识别中     │ 逐字稿完成，正在提取书名和作者               │ 等待，无需操作               │
│ 已识别     │ 书名和作者置信度达到自动通过要求             │ 可查看或后续修正             │
│ 待确认     │ 低置信度、多候选、作者不确定或字段冲突       │ 打开抽屉确认                 │
│ 未识别     │ 逐字稿中没有明确出现书籍                     │ 可人工补充，也可标记无书籍   │
│ 已修正     │ 用户已经修改模型识别结果                     │ 以人工结果为准               │
└────────────┴──────────────────────────────────────────────┴──────────────────────────────┘
```

建议状态颜色：

- 待识别、识别中：中性灰或处理蓝。
- 已识别、已修正：低饱和绿色。
- 待确认：暖黄色。
- 未识别：中性灰，不使用错误红色。

## 11. 数据与实现边界

当前已有数据可以支持：

- 标题、作者、粉丝量、时长。
- 点赞、评论、分享、收藏。
- 来源 URL、任务状态、当前阶段。
- 采集时间和任务更新时间。
- 逐字稿及其后续书籍识别输入。

需要在实现时补充：

1. 逐字稿完成后立即运行轻量书籍识别，不再等待当前后置书籍阶段。
2. 为任务保存早期书籍识别结果、置信度、识别依据和人工覆盖值。
3. 建立列表分页聚合查询，避免浏览器一次加载全部任务、阶段和 artifact。
4. 将发布时间、评论、分享、收藏等采集元数据整理为稳定列表字段。
5. 为批量阶段操作建立后端接口；未接通的批量按钮不显示为可用状态。

## 12. 待确认项

实施代码前只需要确认以下页面决策：

1. “视频采集”作为独立页面保留，“内容项目库”继续作为首页。

### 13.3 宽屏与移动端处理

- 桌面端保持独立字段，表格支持横向滚动。
- 左侧固定选择、序号、关键词、标题；右侧固定任务/操作。
- 互动字段不能因为屏幕变窄而合并为“互动数据”。
- 移动端改为纵向字段卡片，点赞、评论、分享、收藏仍然逐项显示。
- 书籍、任务状态和操作入口优先级高于低频字段，但低频字段通过“展开详情”保留。

## 14. 操作栏确认稿

操作栏采用“一个状态主操作 + 更多菜单”，不把所有按钮同时塞进表格。

| 任务状态 | 主操作 | 次操作 | 更多菜单 |
| --- | --- | --- | --- |
| 待处理 | 查看 | 取消并删除 | 编辑任务设置、复制源链接 |
| 处理中 | 查看当前阶段 | 停止 | 查看任务、复制源链接；心跳异常时显示“从当前断点继续” |
| 待确认 | 去确认 | 查看 | 查看建议、复制源链接、取消任务 |
| 失败 | 查看错误 | 从失败阶段恢复 | 查看上次产物、复制源链接、取消任务 |
| 已完成 | 查看成片 | 下载 | 查看质检、爆款二创、查看任务、复制源链接 |
| 已取消 | 查看记录 | 复制为新任务 | 复制源链接 |

### 14.1 爆款二创显示条件

- 成片阶段完成。
- 自动质检通过，或已人工审核通过。
- 当前任务不是二创版本。

### 14.2 异常恢复规则

- 不使用含义不清的“重启任务”。
- 失败任务显示“从失败阶段恢复”。
- Worker 心跳超时的处理中任务显示“从当前断点继续”。
- 已完成阶段不得重复执行，避免重复配音、重复生图或覆盖旧成片。
