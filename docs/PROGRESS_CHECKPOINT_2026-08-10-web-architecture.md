# 2026-08-10 网页整体架构改造节点

## 当前阶段

- 主阶段：开发阶段
- 次阶段：回归阶段
- 本节点目标：将原有“侧边任务列表 + 单任务阶段页”升级为可继续扩展的内容生产工作台架构。

## 本节点已完成

- 新增统一应用壳层，包含顶部主导航、左侧公共工作区和主内容区。
- 首页升级为内容项目库，增加项目统计、按书籍聚合、最近任务、搜索和状态筛选。
- 保留原有任务创建、实时任务更新和任务详情路由，未改变 worker 与数据库阶段流转。
- 任务详情新增“流程工作台 / 生成前确认”双视图。
- 生成前确认直接读取现有阶段状态，统一显示逐字稿、清洗稿、改写稿、图片、书籍、配音和输出规格的就绪状态，并可返回对应阶段处理。
- 知识图文入口接入同一应用壳层，减少不同模块之间的页面割裂。
- 增加桌面、平板和手机响应式规则，以及 `prefers-reduced-motion` 降低动画支持。
- 视觉方向改为暖白、浅灰和克制的鼠尾草绿，强调中老年友好、低压力和高可读性。

## 使用者视角判断

- 首页从“创建任务表单”提升为“项目管理入口”，用户可以先看全局，再进入具体任务。
- 生成前确认解决了最终成片前信息散落在八个阶段的问题，减少漏确认和反复跳转。
- 桌面端保留高信息密度，手机端改为抽屉导航、两列指标和单列内容卡片。
- 无头浏览器截图发现移动导航全称与简称重复，已在本节点内修正。
