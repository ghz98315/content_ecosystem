# 全页面 ASCII 线框图总目录

> 状态：规划总览稿。每个页面先有可阅读的 ASCII 框图，再进入前端实现。
>
> 原则：统一内容生产工作台框架；桌面优先信息密度，手机端改为纵向任务卡或全屏工作区；不把无后端能力的操作伪装成可用按钮。

## 0. 全局框架

```text
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ 内容创作台   内容项目   视频采集   书籍库   知识图文                       音色管理     │
├────────────┬────────────────────────────────────────────────────────────────────────────┤
│ + 新建任务  │ 页面标题 / 当前任务上下文                                  工作区状态 · 用户 │
│            ├────────────────────────────────────────────────────────────────────────────┤
│ 内容项目   │                                                                            │
│ 视频采集   │                         当前页面正文区域                                  │
│ 书籍库     │                                                                            │
│ 知识图文   │                                                                            │
│ 音色管理   │                                                                            │
└────────────┴────────────────────────────────────────────────────────────────────────────┘
```

- 桌面端：左侧导航 + 顶部导航；正文最大宽度受控，不做营销式 Hero。
- 平板：侧栏可收起，表格允许横向滚动。
- 手机：侧栏改为抽屉；表格改字段卡；抽屉改全屏页面层。

## 15. 需逐页确认的顺序

1. 视频采集工作台：已完成字段和操作栏规划。
2. 书籍库与聚合抽屉：已完成卡片、抽屉和跳转规划。
3. 逐字稿与清洗稿：已完成对照工作台规划。
4. 改写审阅页。
5. 图片工作台。
6. 书籍确认页。
7. 配音与字幕页。
8. 成片与质检页。
9. 知识图文页面。
10. 音色管理与声音复刻页。

每一页在得到确认前，只调整线框和交互口径；得到确认后才进入对应页面的代码实现和视觉验收。
