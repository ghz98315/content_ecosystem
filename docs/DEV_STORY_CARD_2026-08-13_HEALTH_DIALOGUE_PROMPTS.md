# 健康双人播客提示词开发素材卡

- 阶段：开发阶段，次阶段为真实任务验收。
- 模块：健康类双人播客改写、结构质检、健康合规复用。
- 用户价值：健康来源稿可改写成自然的主持人/嘉宾问答，同时保留原稿爆点、事实边界和现有健康审核标准。
- 关键变化：健康双人首发与二次发布改用独立提示词；主持人承担钩子、追问和总结，嘉宾承担解释、案例与边界澄清。
- 关键设计决策：单人口播提示词保持不变；CTA 继续由书籍阶段生成；不引入固定人设、第三角色和来源稿之外的诊疗建议。
- 风险收口：结构门要求角色交替、明确提问、有效轮次长度及嘉宾解释信号，避免把单人口播机械切段。
- 验证证据：Worker 定向回归 86 项通过，Python 编译通过，提示词加载检查通过，Next.js production build 通过。
- 待验证：未上线；需部署最新 Worker 后用真实健康双人任务验收对话自然度、两种音色区分和最终成片节奏。
- 可写角度：双人播客工作流不是在单人口播稿前加两个角色名。
