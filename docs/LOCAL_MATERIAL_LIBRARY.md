# 本地素材成片

- Worker 从 `LOCAL_MEDIA_LIBRARY_ROOT` 读取原视频；未配置时使用本机的 `D:\Obsidian\99_剪映素材库\剪映公用素材库`。
- `10_通用画面` 与对应内容类别（`20_国学`、`30_健康`、`40_城市场景`）作为候选目录；`00_待整理` 不参与选片。
- 素材保留原文件名和原路径。选片索引只记录相对路径、大小、时长、画幅与截取起点；源 MP4 不上传到数据库或云存储。
- 计划使用连续片段。优先正常速度，时长不足时可使用 0.5 或 0.3 倍速。相邻镜头避免复用同一源片。
- 编码前再次检查源文件位于素材库内、大小未变化、片段时长充足，并抽样检测片头及片尾画面运动。任务索引与小幅预览图可进入私有产物存储。
- 原片文字、水印和授权来源不能仅靠运动检测判定；有明显原片文字的素材列于 `local_materials.EXCLUDED_NAMES`，新素材进入生产前仍需视觉抽查和来源记录。
- 新国学模板为 4:3 主画面。采用本机素材时成片导出为 720×1280：选片先验证 4:3 裁切后的有效宽度至少 720 像素，再按比例裁切；不允许把不足 720 像素的素材放大进成片。更高分辨率素材优先进入选片。旧任务的 1:1 模板快照仍有效。
- 封面从选中素材的预览帧中比较亮度、对比与细节，选择一帧作为开头 0.5 秒静态封面。源画面仍需人工抽查；自动分数不能判断版权或画面内容。
- Supabase 单文件限制会让长视频的线上预览压缩过重。本机 Worker 会额外输出约 1.8 Mbps 的清晰版到 `worker/output/high-quality-exports/<任务ID>/`，页面提供本机路径；本机清晰版与线上成片均保留 7 天。此路径只在运行 Worker 的电脑可用。
- 2026-10-26 清理 9 组 SHA-256 完全相同的副本，每组保留一份；清理清单存于 `worker/output/asset-audit/dedup-20261026.json`。
