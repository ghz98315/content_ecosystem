## 1. 页面定位

TTS 页面负责把已确认的最终文案生成音频，并展示字幕时间轴预估。它不是音色管理页：

- TTS 页选择本任务使用的 Provider、音色 profile 和语速。
- 音色管理页负责创建、试听、停用和管理复刻音色。
- 已进入 TTS 的任务使用已快照的配置，不能因为全局默认音色变化而改变。
- Edge 作为手工兜底 Provider 保留，但不自动把同一任务混合成两种音色。

## 3. 顶部统计卡

固定展示四项，数字来自当前任务快照：

| 卡片 | 内容 | 规则 |
| --- | --- | --- |
| 文案字数 | 5027 字 | 读取已确认改写稿，不读取临时草稿 |
| 预估口播 | 15:48 | 根据当前语速和文本估算，生成后替换为真实时长 |
| 音频状态 | 未生成、生成中、已生成、失败、待确认 | 同时显示状态文本和颜色 |
| 成片预估 | 2 条 · 15:48 / 条 | 按当前版本和输出数量计算，不代表已生成文件 |

文案或语速发生变化时，预估卡立即更新，并显示“需重新生成音频”。

## 4. 生成配置

### 4.1 Provider 与音色

```text
Provider [CosyVoice ▼]
模型    cosyvoice-v3.5-flash
音色    [复刻音色 profile ▼]
        当前 Voice ID：cosyvoice-...（可复制）
状态    已配置 / 不可用 / 需重新试听
```

- Provider 只显示已在服务端配置并通过健康检查的选项。
- CosyVoice 音色必须与绑定模型一致；不允许在页面上把 v3.5 音色伪装成 v3 音色。
- Edge 作为明确的手工兜底选项显示“Edge 兜底”，切换后需要确认并重新生成完整音频。
- API Key、内部 endpoint 和工作区 ID 永不显示在网页上。

### 4.2 语速

- 使用下拉或分段控件：`0.85x`、`1.00x 标准`、`1.15x`、`1.30x`，允许新任务扩展自定义值。
- 语速改变只影响尚未生成或明确重跑的任务，不修改已完成音频。
- 改变语速后同步刷新分段时长预估和预计成片时长。

## 5. 生成与试听状态

```text
待生成       [生成音频]
生成中       [生成中…]  已完成 3 / 8 段 · 可查看已完成分段
已生成       [重新生成音频]  [播放完整音频]
失败         [查看错误] [从 TTS 阶段重试]
待确认       [试听] [确认音频并进入 AI 场景图]
```

- 生成中允许试听已完成的分段，但不能误显示为完整音频已生成。
- 重新生成必须提示将使字幕时间轴和成片阶段失效。
- Provider 失败时显示具体错误、失败批次和可执行的 Edge 兜底操作。
- 音频生成成功后自动加载完整音频播放器；签名 URL 失效时提供重新加载。

## 6. 分段时长预估区

- 每行显示片段编号、预计/真实时长、对应文本摘要和状态。
- 生成前显示估算；生成后用真实音频边界替换估算值。
- 点击片段可播放单段音频；失败片段只提供局部重试，不重复已成功批次。
- 列表固定高度并独立滚动，避免长文案撑大页面。
- 分段顺序必须与字幕时间轴、图片镜头顺序一致。

## 7. 与字幕和成片的边界

```text
确认改写稿
    ↓
TTS 生成音频 + 词/句级时间轴
    ↓
字幕校准（使用真实音频边界）
    ↓
AI 场景图与成片渲染
```

- TTS 输入必须是已确认改写稿和可编辑 CTA 的最终版本。
- 书名在 TTS 输入中保留《书名》，字幕同样保留书名号，不允许出现乱码或错误替换。
- 数字读取规则在清洗阶段完成，TTS 页只展示最终文本；需要修改时返回清洗稿或改写稿处理。
- 音频真实时长生成后，后续镜头和字幕按真实边界重新校准，不能继续使用旧的平均时长。

## 8. 响应式布局

- 桌面 `>=1200px`：保留左侧阶段导航；配置区与分段预估左右两栏。
- 平板 `768-1199px`：左侧导航收窄；配置区和分段区上下排列。
- 手机 `<768px`：阶段导航横向滚动；统计卡两列；分段列表全宽；底部固定主操作。
- 音频播放器保持稳定高度，Voice ID 和长文本允许换行，不能造成布局抖动。

## 9. 本页验收口径

1. 能明确看出当前 Provider、模型、音色 profile 和语速。
2. 能区分预估时长与真实音频时长。
3. 能播放完整音频和单个分段。
4. TTS 失败时能定位批次并从 TTS 阶段恢复。
5. Edge 兜底必须手工选择，不自动混合音色。
6. 音频确认后才能进入 AI 场景图，后续字幕使用真实时间轴。
