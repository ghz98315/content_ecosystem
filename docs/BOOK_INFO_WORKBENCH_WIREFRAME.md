## 1. 页面定位

书籍信息页负责确认后续成片所使用的书籍身份和营销文案：

- 书名、作者、国籍和识别置信度。
- 人工上传的受控书籍封面。
- 视频号长标题、短标题和话题标签。
- 可人工编辑的收尾 CTA。
- 人工确认结果覆盖模型识别结果，并被后续配音和成片读取。

参考图的视觉层级可以采用，但阶段编号必须以本平台真实八阶段流程为准，不照搬参考系统的 `STEP 05`。

## 3. 书籍身份区域

### 3.1 字段

| 字段 | 编辑规则 |
| --- | --- |
| 书名 | 可编辑，显示时自动加《》；数据库保存规范化书名，不重复嵌套书名号 |
| 作者 | 可编辑，不得锁死模型结果 |
| 国籍 | 可编辑；没有可靠信息时允许留空，不能模型臆造 |
| 封面 | 仅人工上传、历史受控封面或明确授权来源；不随机生成 |
| 置信度 | 只读，显示模型识别程度和识别来源 |
| 识别依据 | 只读，保留逐字稿原句，便于人工核对 |
| 候选结果 | 低置信度或多候选时显示，可一键填入表单后再人工确认 |

### 3.2 操作

- `AI 重新识别`：只重新分析逐字稿，不直接覆盖当前表单。
- 新识别结果作为候选展示，由用户选择是否采用。
- 已存在人工修正时，按钮文案显示“重新识别候选”，避免误以为会覆盖人工值。
- 保存后写入稳定 `book_id`，供书籍库和采集页聚合。

## 4. 封面区

- 固定书封比例，建议 `2:3`；无封面时使用统一占位，不随机 AI 生成。
- 支持 PNG、JPEG、WebP，前端显示格式、大小和上传进度。
- 替换封面前预览，确认后才保存。
- 新封面供本任务后续片头/片尾使用，并成为书籍库受控封面候选。
- 替换封面不修改已经生成完成的历史成片。

## 5. 视频号标题区

参考图中左右两列信息结构可以保留，但要增加明确的选择状态。

### 5.1 长标题

- 展示 5-8 条候选，包含完整视频标题和可选标签。
- 每条独立选择，当前采用项有单选状态和“已选”标记。
- 点击标题复制不是默认行为，避免误触；复制使用独立图标按钮。
- 支持直接编辑选中的标题。

### 5.2 短标题 / 封面文案

- 展示 4-6 条短标题，控制适合封面的字数。
- 与长标题分别选择，不要求候选行严格一一对应。
- 书名可以出现，但必须使用《书名》并检查乱码。
- 禁止健康违规文字出现在封面文案；数字和标签可以按规范出现。

### 5.3 重新生成

- `重新生成视频号标题` 只刷新标题候选，不修改书籍资料、CTA 或已选封面。
- 重新生成前保留当前已选标题，用户确认新候选后才替换。
- 显示生成时间和模型来源，用于判断候选是否为最新版本。

## 6. CTA 编辑区

- CTA 必须始终可人工编辑，不能只展示模型结果。
- 默认引用当前确认书名，并自动使用《》格式。
- 提供字数、合规和书名一致性检查。
- 禁止承诺疗效、绝对化结果或诱导违规表达；使用中性、生活化引导。
- `保存草稿` 不推进任务，`确认书籍信息并继续` 才把 CTA 写入后续 TTS 输入。

## 7. 状态与保存

```text
识别中       显示骨架，不允许保存空结果
待确认       可编辑全部字段，[确认书籍信息并继续]
已修正未保存 显示底部未保存提示，离开页面需确认
保存中       禁用重复提交，保留页面内容
保存失败     字段不清空，显示具体错误和重试
已确认       默认只读，可通过“重新编辑”创建新版本
```

- 保存应一次性提交书籍、标题、短标题、CTA 和封面引用，避免部分字段成功、部分字段失败。
- 人工字段记录来源和版本；Worker 后续重跑不得静默覆盖。
- 已确认内容重新修改时，明确提示会使 TTS 和成片阶段失效。

## 9. 本页验收口径

1. 书名、作者和国籍都可修改。
2. 封面只能使用人工或受控来源，不随机生成。
3. 长标题和短标题分别选择、复制和编辑。
4. CTA 可以人工修改并进入后续 TTS。
5. 人工修改不会被后续模型结果覆盖。
6. 重新生成标题不会改动书籍资料和 CTA。
7. 已确认内容再次修改时，明确提示影响 TTS 和成片。
