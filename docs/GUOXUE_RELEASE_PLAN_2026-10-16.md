# 国学独立模板发布与全流程验收计划

1. 固定 `guoxue-v1`：4K九宫格、4:3主体与模糊填充、朱红毛笔主标题、52像素楷体副标题、毛笔正文字幕、楷体脚注。健康、历史社科、经管分别保存自己的模板快照。
2. 创建任务时先处于配置中，完整保存图像与成片配置后再进入待处理队列。导入入口和首页入口保持一致，避免抢先执行。
3. 将背景音乐上传、试听、音量、移除入口提前到配音节点；成片节点共用同一配置，保存与渲染并发时明确拦截。
4. 每次节点执行记录开始、结束和实际处理时长；任务页显示从创建至成片的总耗时，以及处理与等待耗时。历史任务缺少执行记录时明确标注，禁止伪造处理时间。
5. 回归检查模板隔离、字幕对齐、独立封面、字体、BGM混音、断点恢复与重跑范围。
6. 构建、提交、发布前端，重载本地Worker；运行独立验收任务，保留真实外部配音与已确认文案的匹配关系，检查完整结果并记录任何复用或人工确认步骤。

沿用现有数据库结构，以阶段参数保存模板，以 artifacts 记录执行计时；不改变二创模型和配音方式。真实生图沿用用户已授权的APIMart九宫格方式。
