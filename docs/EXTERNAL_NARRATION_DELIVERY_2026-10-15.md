# 外部配音入口：实现与发布说明

日期：2026-10-15。最新状态：前端、数据库已上线，本机Worker常驻，复用图片的真实制片链路验收完成；最终记录见 `EXTERNAL_NARRATION_RELEASE_2026-10-15.md`。以下保留实现与逐步推进记录。

## 使用路径

新任务可选择“确认文案后上传外部配音”，默认使用该方式；历史任务保持原配音方式。任务配音页也可以切换方式。采集、逐字稿、清洗、改写候选、文案及封面确认流程保持原样。

确认改写稿后：打开配音页 → 下载确认朗读稿 → 在线下制作纯人声 → 上传 WAV/MP3 → 等待 Worker 识别 → 核对疑似朗读差异 → 修改最终字幕稿或校准字幕起止时间 → 保存并重新对齐 → 试听核对后勾选确认 → 继续生图和渲染。

音频限制：最多 200MB，0.1 秒至 60 分钟；存储服务若设置更小的 bucket 限制，以实际配置为准。支持文件重传、上传后继续提交、刷新恢复，以及当前任务的历史版本记录。

## 实现范围

- 新增 `external_narrations` 版本表、RLS、拥有者操作 RPC、带代次令牌的 Worker 完成事务。上传确认检查 Storage 对象和大小；旧版本提交、过期字幕确认、过期 Worker 完成均被拒绝。
- 外部模式不调用任何 TTS Provider；等待文件或人工核对时阻止生图和渲染。
- 保留原音频；解码制作 PCM WAV 副本用于后续处理，不自动改语速、音调、停顿，不把多个语音片段重新拼接。
- 复用本地 faster-whisper 获取词时间戳，以数字读法归一化做文本约束匹配，列出漏读/增词/替换疑似差异。字幕文字不会回写或自动改写上游二创稿。
- 未匹配的字幕不伪造起止时间；需要逐句试听与人工时间校准。编辑后的字幕须通过全文一致、每条不超过14字、时间递增、无重叠、不越过音频末尾的 Worker 校验。
- 审核只发布经过校验的音频/字幕文件引用。成片读取同一已确认版本，避免“最新音频”与“最新字幕”错配。
- 配音时间改变而字幕稿相同时复用图片；字幕稿改变时重新排队生图，按文稿哈希隔离图片缓存，避免错误复用旧图。该版本按整份稿件失效图片，尚未实现逐分镜局部重生图。
- 外部模式重跑图片或全量重生图保留已确认配音；配音重跑仅失效成片；上游重新改写会使旧配音确认失效。

## 发布顺序

1. 确认旧 Worker 停止领取任务，避免旧代码把外部配音任务当作自动配音执行。
2. 备份数据库结构，按顺序完成已有迁移至0033，再执行 `supabase/migrations/0034_external_narration.sql`。新 Worker 的媒体领取依赖新增RPC，不能先启动新 Worker 再补迁移。
3. 在生产 Worker 的现有虚拟环境内确认 `worker/requirements.txt` 中的 faster-whisper、imageio-ffmpeg、jieba 等依赖可用。保持已有 WHISPER_MODEL / WHISPER_DEVICE / WHISPER_COMPUTE 设置，首次使用可能下载模型。
4. 更新 Worker 后先仅对全新隔离任务运行，使用 WORKER_TASK_ID 限定任务；勿直接开启全局历史队列。
5. 发布前端及 API；沿用 Supabase 公共配置、服务端 service key 与 artifacts 私有 bucket。新增流程无需新的云端 TTS 密钥。
6. 在隔离任务中验证：确认文案 → 上传 → 替换 → 识别差异 → 调整字幕 → 确认 → 生图 → 成片；特别检查长静音、数字、书名、片头偏移和尾部同步。
7. 验收后再恢复常规 Worker 领取范围。若回滚前端，先停止外部模式任务的 Worker；保留版本表和音频，避免旧 Worker 误执行。

本轮没有执行上述生产操作，也没有重跑历史任务、提交付费生图或上传用户文件到生产存储。

以上为最初交付状态；以下上线推进记录更新了数据库执行情况。
