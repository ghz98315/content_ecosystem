# 开发素材卡：图片全量重生成

- 阶段：开发与回归阶段。
- 模块：图片生成、成片渲染、任务恢复控制。
- 用户价值：视觉风格更新后，用户可以只重新生成图片和最终成片，不必重新采集、转写、清洗、改写或配音。
- 旧限制：普通重跑沿用断点续跑策略，会复用已有图片与图片供应商任务，导致新提示词无法生效。
- 关键变化：新增受任务归属校验保护的全量重生操作；只删除当前任务的 image/render 产物及对象存储文件，并清除图片供应商任务缓存。
- 关键取舍：图片审核记录保留审计价值；历史单图替换请求标记失效，避免旧替换图覆盖新分镜。
- 验证证据：Worker 全量 97 项测试通过；Next.js production build 通过；git diff --check 通过。
- 待验收：执行数据库迁移并部署后，在真实图片任务中点击“按当前风格全量重新生成”，用隔离 Worker 验证 image 与 render 的完整新产物闭环。
