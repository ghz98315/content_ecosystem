# 来源元数据与发布内容表开发素材卡

- 阶段：开发与回归阶段，次阶段为线上迁移和真实任务验收。
- 模块：任务创建、视频采集元数据、书籍确认、成片发布信息。
- 用户价值：单条任务创建后直接进入处理界面；原标题、话题标签和书名各自有唯一结构化来源；成片页可直接复制发布信息。
- 关键变化：采集时将标题与 `#标签` 分开保存；标题界面只显示前 20 字，悬浮显示全文并可点击复制；最终书籍阶段同步采集台书名信号。
- 发布交付：`book.json` 固化原标题、来源标签和不超过 16 字且无标点的建议发布标题，成片页支持逐项复制和复制整表。
- 风险收口：书籍人工确认会保存当前页面完整快照，避免确认后重新调用模型造成书名漂移；迁移前 Worker 可回退运行。
- 验证证据：Worker 111 项测试通过，Python 编译通过，Next.js production build 通过，差异检查通过。
- 待验证：执行 `0023_source_tags.sql`、部署 Web/Worker 后，用任务 `6159fa5b-1f00-48bf-9edc-c247a80bba8e` 验收五个来源标签、书名一致性和发布内容表。
- 可写角度：内容流水线的交付不应止于视频文件，还要保留可直接发布和继续选题的数据。
