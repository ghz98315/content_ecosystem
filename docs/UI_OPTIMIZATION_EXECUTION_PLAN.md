## 执行原则

- 先统一基础 UI 和任务详情框架，再逐页实现业务工作台。
- 优先复用当前真实数据和接口，不展示没有后端能力的假按钮。
- 现有八阶段 Worker 顺序保持不变。
- 所有页面同时覆盖桌面、平板和手机布局。
- 每个切片完成后执行生产构建，并记录已验证与待验证边界。
