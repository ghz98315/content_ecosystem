# 历史类短视频流程优化开发规划书

更新时间：2026-08-22

## 1. 目标与范围

将历史类图书短视频从“按字数/时长平均切分画面”的生产方式，优化为“先理解全文、再规划经典画面、最后生成成片”的总导演流程。

本轮范围包括：

- 历史类文案深度改写、CTA 标记与可选书名处理；
- 三套历史视觉风格及生产设置中的手工选择；
- 生图前的全文分析、事件/人物/场景拆解、封面确认和代表性画面确认；
- 九宫格候选生成与后台自动选图；
- 1 分钟视频最多 3 张最终画面，封面计入上限；
- 历史类统一轻微 Zoom In 与低密度随机雪花动效；
- 历史类单人口播声音复刻优化，沿用既有“历史讲述” CosyVoice2 配置；
- 所有历史规则与健康类流程、参数、音色和提示词隔离。

不在本轮范围内：

- 双人历史对话；
- 自动补全不存在的书名；
- 新增历史类 CTA、优惠、卖点或购买承诺；
- 把 CTA 或书名制作成独立一页；
- 修改健康类默认生产行为。

## 2. 已确认的产品规则

### 2.1 历史画面数量

- 1 分钟视频最终最多 3 张画面，封面包含在 3 张内；
- 默认优先 1-2 张；
- 只有文案存在第三个不可省略的关键事件转折时才使用第 3 张；
- 不为填充时长增加普通过渡图；
- 每张图必须对应明确的人物、事件、场景或情绪转折，并具备点睛价值。

九宫格是候选图片的生产方式，不等于最终镜头数量。系统可生成九宫格，但最终只使用与分镜规划最匹配的代表画面。

### 2.2 三套历史视觉风格

生产设置中由用户手工选择，并随任务快照保存：

1. 方案一：水墨绢本叙事
   - 泛黄纸本、墨线、水墨手绘、低饱和赭石土黄；
   - 适合行旅、人物生平、隐逸、家国叙事和回忆感场景；
   - 强调环境、留白、景深和行进方向。

2. 方案二：古工笔厚涂史诗
   - 中式古工笔与厚涂油画融合、暗金低饱和、烛光或侧光；
   - 适合人物特写、谋略、审案、权力博弈和关键抉择；
   - 强调人物面部、服饰、道具和时代环境。

3. 方案三：历史英雄叙事
   - 保留现有 `history_heroic`；
   - 继续作为独立历史风格方案，不与前两套提示词混合。

所有风格预览图由生图模型生成，必须无文字、无字幕、无水印。参考图中的文字和水印只作为构图参考，不进入生产图片。

### 2.3 封面与动效

- 第一张实际画面必须是全文总结性封面；
- 人物类封面突出人物在典型时代场景中的状态；
- 事件类封面突出最经典、最具辨识度的事件瞬间；
- 不额外制作封面页、书名页或 CTA 页；
- 历史类默认开启轻微逐步放大；
- 历史类默认开启低密度、随机、低透明度雪花粒子；
- 雪花只作氛围点缀，不遮挡人物、道具、字幕和关键构图；
- 雪花作为 render 动效处理，不强制烧录进源图片。

### 2.4 文案、CTA 与书名

改写阶段完成：

- 开头文字完整保留；
- 中段深度重构，保留人物、事实、时间线、数据、核心观点和情绪强度；
- 允许调整标点、语序和停顿以适配口播，但不删减正文事实内容；
- CTA 沿用原文案已有内容，只允许调整语序和口语表达，使其更适合中老年听感；
- 不新增 CTA、卖点、优惠、链接承诺或夸大性购买话术；
- 改写产物中单独标记 CTA 原文和润色后文本；
- CTA 进入完整口播稿，但不单独成为视频一页。

书名规则：

- 参考文案提供书名时，提取并保留；
- 未提供书名时，不推断、不补全、不调用书名识别；
- 无书名时不阻塞流程，不生成书名页，不展示虚构书名；
- 原文中的“这本书”“这部作品”等泛指表达尽量保留原意。

建议 rewrite artifact 字段：

```json
{
  "rewrite_text": "完整改写稿",
  "hook_text": "保留的开头",
  "body_text": "重构后的中段",
  "cta_original": "原 CTA，可为空",
  "cta_revised": "润色后的 CTA，可为空",
  "cta_start": 0,
  "cta_end": 0,
  "book_title": "可为空",
  "book_title_source": "reference_copy|absent"
}
```

## 3. 目标流程

```text
任务创建
  -> 选择 content_category=历史类/social_science
  -> 选择历史视觉风格并保存任务快照
  -> ingest/transcribe/clean
  -> rewrite：深度改写 + CTA 标记 + 可选书名
  -> history_director_analysis：全文分析与关键画面规划
  -> image：按规划生成九宫格候选并自动选择代表图
  -> book：仅保存已有书名/书籍信息，不因缺书名阻塞
  -> tts：历史讲述 CosyVoice2 单人口播
  -> render：封面、关键画面、Zoom In、雪花、字幕和成片
  -> quality：检查事实、画面对应性、数量上限、音频和视频完整性
```

## 4. 分阶段开发任务

### P0：需求配置与隔离边界

- 增加历史类专属配置命名空间；
- 明确历史类与健康类提示词、CTA 规则、视觉参数、TTS 参数的读取边界；
- 为历史任务保存视觉风格、动效和声音配置快照；
- 保证旧健康任务和健康类默认配置行为不变。

验收：健康类回归测试通过，历史配置不会被健康任务读取，历史任务不会继承健康类视觉/声音设置。

### P1：历史类改写与 CTA/书名结构化

- 新增历史类 rewrite prompt 和规则；
- 生成 hook/body/CTA/book_title 结构化 artifact；
- CTA 单独标记原文和润色稿；
- 书名缺失时显式记录 `absent`，不触发书名识别；
- 增加 CTA 未新增内容、正文事实保留和书名可选的测试。

验收：给定历史参考文案，改写稿可直接用于 TTS，CTA 可追踪，缺少书名时流程正常完成。

### P2：三套视觉风格与参考预览

- 固化三套风格 ID、正向提示词、负面提示词和适用说明；
- 使用生图模型生成无字、无水印参考预览图；
- 在生产设置中提供手工选择和预览；
- 将选择写入任务级 image snapshot；
- 仅历史类显示三套风格，健康类不出现历史风格选项。

验收：三套预览图可查看，选择后任务快照稳定，重跑不会被全局设置覆盖。

### P3：总导演式全文分析与分镜规划

- 新增历史类分析 artifact；
- 从完整改写稿识别人物、事件、地点、时代、动作、因果和情绪转折；
- 规划一张封面和 0-2 张关键事件图；
- 检查最终画面数量不超过 3 张；
- 检查每张图与文案对应、画面不重复、封面能概括全文；
- 分析结果默认后台保存，不要求用户查看全部中间推理。

建议 artifact 字段：

```json
{
  "cover": {"purpose": "全文总结", "scene": "...", "must_include": []},
  "beats": [
    {"index": 1, "purpose": "关键事件", "scene": "...", "characters": [], "action": "...", "must_include": []}
  ],
  "selected_count": 2,
  "checks": {"cover_representative": true, "beats_match_copy": true, "no_redundancy": true}
}
```

验收：相同文案重复运行时，规划结果可追溯；规划失败时阻止付费生图，不提交不完整任务。

### P4：九宫格候选生成与自动选图

- 按每个规划 beat 生成九宫格候选；
- 固定风格模板和负面提示词，剧情描述由 beat 注入；
- 自动评估候选与 beat 的匹配度；
- 自动选择代表图，不要求人工挑图；
- 保留原图、九宫格、裁切边界、候选评分和最终选择记录；
- 无文字、无字幕、无水印作为硬检查。

验收：每个最终画面都有对应 beat 和来源九宫格；候选不足或不符合要求时进入可恢复失败，不静默使用普通图片。

### P5：历史类 render 动效与 CTA/书名展示

- 第一张画面使用封面 beat；
- 最多渲染 3 张最终画面；
- 默认统一轻微 Zoom In；
- 默认叠加低密度随机雪花；
- CTA 不独立成页；
- 有书名时仅在既有合适的信息区域轻量显示；
- 无书名时不显示书名占位或虚构内容。

验收：1 分钟任务最多 3 张画面，封面为第一张；CTA 不产生独立页面；动效不遮挡字幕和主体。

### P6：历史类声音优化

- 沿用已有“历史讲述” CosyVoice2 profile；
- 保持单人口播；
- 优化历史人名、地名、古籍名的读法和停顿；
- 检查长文连续性、高潮情绪和句末收束；
- 保持任务级 Provider 快照和整篇回退机制；
- 不修改健康类 narrator35 或健康类默认 Provider。

验收：至少一条真实历史文案完成隔离试听，确认声音自然、连续、无中途换音色，且健康类声音回归不变。

### P7：端到端验收与发布

- 使用真实历史任务验证 rewrite -> analysis -> image -> book -> tts -> render；
- 保存截图、提示词、artifact、质检报告和最终视频；
- 验证重跑只重置当前阶段及下游；
- 验证失败恢复不会重复提交外部生图任务；
- 确认健康类任务无行为回归；
- 再决定是否部署数据库迁移和开启默认生产配置。

## 5. 质量门与失败策略

硬失败：

- 历史分镜未生成封面；
- 最终画面超过 3 张；
- 画面规划缺少文案对应关系；
- 生图候选包含明显文字/水印且无可用候选；
- 音频、视频或主时间轴损坏；
- CTA 被新增或改写成原文不存在的承诺。

警告但不阻塞：

- 字幕标点、长度或轻微断句问题；
- 雪花效果过弱或画面氛围偏差；
- 书名缺失；
- 历史画面风格偏差但仍满足事件对应性。

所有外部生图任务必须在提交前保存任务快照、提示词摘要和幂等键；超时后继续轮询原任务，不重新付费提交。

## 6. 健康类隔离要求

历史类专属：

- rewrite prompt、CTA 规则、书名规则；
- history director analysis；
- 三套视觉风格及负面词；
- 封面规划、画面数量和雪花动效；
- 历史讲述音色和 Provider 参数。

仅共享通用基础设施：

- 任务调度；
- artifact 保存；
- 阶段重跑和恢复；
- 通用渲染器；
- 通用质量报告框架。

禁止：

- 修改健康类默认提示词来兼容历史类；
- 修改健康类 narrator35 或默认 TTS Provider；
- 让历史类任务继承健康类全局环境变量；
- 用健康类分镜数量规则覆盖历史类规则。

## 7. 待补充信息

以下内容不阻塞规划，但在对应阶段开始前需要确认：

1. 三种风格参考预览图是否只展示静态图，还是同时展示短动效预览；
2. 书名存在时，具体显示在画面的哪个既有信息区域；
3. CTA 是否允许在字幕中显示，还是只保留口播；
4. 历史讲述 CosyVoice2 profile 的正式 voice ID、模型和当前参数；
5. 生图模型的候选评分是否先使用规则评分，还是已有视觉模型评分接口。

## 8. 本次确认点

本规划书确认后，执行顺序为：

1. 先生成三套风格参考预览并固化配置；
2. 再实现历史类 rewrite 的 CTA/书名结构化；
3. 然后实现后台总导演分析和分镜 artifact；
4. 接着接入九宫格自动选图和历史 render 动效；
5. 最后优化历史讲述声音并做端到端隔离验收。

在规划确认前，不修改生产代码、不部署迁移、不改变健康类行为。
