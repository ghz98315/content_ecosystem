# 视频封面图工作台 ASCII 线框图

> 状态：细化确认稿
>
> 参考：`ref-doc/ref-page/03.png` 和 `ref-doc/04.png` 的视频封面/首屏信息结构。
>
> 本页的封面是“最终视频封面图”，与书籍封面、正文场景图和视频首屏图分开管理。

## 1. 页面职责

- 使用采集视频原封面、AI 生成封面或人工上传图片作为视频发布封面。
- 允许封面上的标题、副标题、标签和作者信息独立编辑。
- 每个文字图层可独立确定位置、字号、颜色、对齐、行数和背景遮罩。
- 支持生成多个封面风格并选择一个作为当前版本。
- 封面确认后只影响发布封面和列表缩略图，不修改书籍封面、正文场景图或视频首屏图。

## 3. 图片来源

| 来源 | 规则 |
| --- | --- |
| 采集封面 | 展示原视频封面 URL 和预览；可直接作为视频封面底图 |
| AI 生成封面 | 根据标题、书名、作者和选定风格生成，不生成书籍资料封面 |
| 人工上传 | 用户上传指定发布封面，校验格式、尺寸和安全区域 |
| 历史版本 | 仅从当前任务或同一书籍的受控视频封面中选择 |

- 图片来源必须记录在版本元数据中。
- AI 生成封面允许生成多种风格候选，但确认前不覆盖当前封面。
- 清空封面后显示稳定占位和“需要选择封面”的阻断状态，不能输出空白封面视频。

## 4. 可编辑文字图层

默认图层：

1. 主标题。
2. 书名（可关闭，但默认建议保留）。
3. 作者或账号名（可关闭）。
4. 话题标签（可关闭）。
5. 可选副标题或 CTA（需合规检查）。

每个图层都必须保存：

```text
layer_id
text
visible
x_percent
y_percent
max_width_percent
font_family
font_size
font_weight
line_height
align
color
shadow
background
safe_area_status
```

文字编辑要求：

- 文本内容、图层顺序和显示状态可单独修改。
- 位置优先使用画布拖拽，辅助输入 X/Y 百分比，保证不同分辨率稳定。
- 提供顶部、中部、底部和四角的快捷吸附位置。
- 支持网格、中心线和安全区域提示。
- 文字超出安全区、被裁切或遮挡时，保存按钮显示警告并阻止直接确认。
- 书名始终规范为《书名》，不允许乱码或错误嵌套书名号。
- 违规词不能通过谐音、拼音或拆字方式绕过；应替换为合规中性表达。

## 5. 画布与预览

- 默认展示平台目标比例，并提供实际移动端裁切预览。
- 画布上的每个图层可点击选中，选中后显示边界框和拖拽控制点。
- 支持撤销、重做、恢复推荐排版。
- 预览不直接把编辑器辅助线烧进最终图片。
- 生成封面时保存“底图版本 + 文字配置版本”，便于后续重新渲染而不重新生成底图。

## 6. 视频封面与视频首屏图边界

```text
书籍封面（书籍信息页单独上传）
                 └── 书籍资料、书籍卡、书籍信息

视频封面（本页编辑）
                 └── 发布封面、列表缩略图

视频首屏图（成片前确认）
                 └── 视频第一帧、片头画面
```

- 三者使用不同字段和版本，不互相覆盖。
- 视频封面文字配置不会烧录进正文场景图。
- 视频首屏图可以引用视频封面底图，但引用关系必须明确记录。

## 8. 本页验收口径

1. 视频封面与书籍封面、视频首屏图完全分离。
2. 封面底图来源可追溯，可使用采集封面、AI 生成或人工上传。
3. 封面标题、书名、作者、标签和 CTA 均可独立编辑。
4. 每个文字图层可以独立调整位置、大小、颜色、对齐和背景遮罩。
5. 支持安全区、移动端裁切和文字溢出检查。
6. 保存文字配置时不必重新生成底图。
7. 违规文字必须合规替换，不允许谐音或拼音规避。
