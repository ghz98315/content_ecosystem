# Worker 1.2 接线说明

## 生效范围

单人口播改写入口加载共享生产提示词，再按领域追加 guoxue.md、health.md 和 rewrite_skill_contract.txt；双人播客保留原流程。不是将整个 SKILL.md 当系统提示词粘贴进去。模型和连接配置沿用现有配置。

二创节点可选自动、国学、健康、混合、通用，保存于 stages.params.rewrite_domain。新任务按内容类型同时保存对应的文案领域、清洗/合规分类和画面模板；旧 content_category=health 不能单独判为健康稿。正文经典与健康信号并存时按混合规则；领域冲突停在 needs_review，页面选择后重跑。关键词判断存在误报/漏报，用户需要核对实际领域；通用选择不能绕过已识别健康主张的规则。

## 输出与证据

保留 rewritten_remainder、tail_text、rewrite_strategy、book_title、book_title_source。追加 information_card（最多24项）和 rewrite_outline（最多16项）：信息卡原文引用必须能在原稿找到；提纲引用有效卡片且成稿锚点必须实际存在。保存规则版本、文件指纹、领域选择依据和核对状态，前端可展开阅读。

信息卡、提纲和正文在同一次模型响应中生成，不是独立事实审核模型，也不证明全部事实已覆盖。程序只校验引用、关联与落点；人物归属、观点含义、真实出处仍需审稿。source_order_changed只是信息卡引用顺序诊断，不足以证明独立叙事结构。外部文皮皮状态仍为“未实测”，不生成预测分数。

## 有限返工与恢复

保持程序提供的钩子逐字拼接、分类字数区间、分段对照和初稿加最多3次修订。健康类85%—90%，山河人文90%—110%，其他类别85%—110%；非健康自动生成目标至少95%。每次调用前，将占用次数和已有稿保存至私有 artifacts 的 rewrite-progress 路径，再发送请求。相同输入/规则/要求的中断执行继续原轮数，预留但未收回的请求也占一次，不隐性追加第5次。下载旧进度失败时停止，避免盲目重发。

局部复用或来源报幕问题能定位到部分段落时，返回 paragraph_edits，由程序复用其余段落；全局篇幅、事实或结构问题仍允许完整重构。每轮以原稿检查全文，不用上轮字数作为新基准。城市景点同一请求返回两提纲、内容形态、选择依据、地点记忆点及原稿事实绑定；只检查字段和落点，不宣称联网核验或传播效果实测。

完成交付后主动重跑或更改输入/领域/要求会开启新一轮。模型传输层重试沿用现有实现，不等于额外的内容修订。进度保存、成稿登记和阶段状态不是一个跨存储事务，完成交接中断时仍可能需要恢复处理；不声称严格一次交付。

保留择优、原有合规审核、字数和本地复用检查、人工确认门。数字目前仍使用既有字面保护词检查，中文与阿拉伯数字等价可能误报，应人工核对，尚未实现完整数值语义解析。常规配音字幕自动对齐规则不受影响。

## 回归范围

本轮使用虚构文案和模拟模型响应验证路由、元数据、次数恢复及旧流程兼容；不发送真实稿件做额外试验。真实模型二创质量和外部检测分数须在下一轮获授权业务测试中单独评估，不能由单元回归代替。
