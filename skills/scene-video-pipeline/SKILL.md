# 山河人文生产规则 v1.0

使用独立模板 scene-v1。二创读取 [rewrite.md](references/rewrite.md)，逐镜规划读取 [visual-rules.md](references/visual-rules.md) 与 [storyboard.md](references/storyboard.md)。文档中的初始化招呼与交付代码块属于原始参考，不作为生产API的输出格式；生产输出遵守调用端JSON契约。

- 二创先规划信息卡、结构和字数，规划95%-110%，执行下限85%，保留程序划定的钩子，最多三次返工。新增事实须有可追溯资料，不凭记忆补造。
- 分镜以已确认稿为唯一正文。只移动边界，拼接后字符、标点和顺序完全一致。按有效字50-80字、语义和地点边界切分；例外记录原因。
- 一镜一主要主体，每镜独立路由校园、自然、古迹、城市、街区或转场规则。正文不拼接互不关联的地点，不提前揭晓悬念。
- 9:16满屏写实纪实摄影，四宫格2K源图，每格一独立竖图；8K是风格描述，不是实际分辨率承诺。
- 单独生成封面，允许按全文创意拼接多个地点，不添加创意合成标记；标题由后期排版。
- 封面0.5秒，配音从首帧开始；主副标题只在封面显示；可编辑脚注默认“图片由AI生成”，全片持续。
- 用任务保存的模板快照；不读取国学字体、横图布局或健康视觉默认值。
