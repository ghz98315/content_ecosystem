# 山河人文生产规则 v1.1

使用独立模板 scene-v1。二创读取 [rewrite-production.md](references/rewrite-production.md)；原 rewrite.md 仅保留为V3.1历史来源，不加载到生产。逐镜规划读取 [visual-rules.md](references/visual-rules.md) 与 [storyboard.md](references/storyboard.md)。生产输出遵守调用端JSON契约。

- 二创识别内容形态，比较两个简短提纲，为每个地点绑定记忆点、事实和成稿锚点；规划至少95%、目标97%，执行范围90%-110%。保留程序划定钩子，最多三次返工，局部修改由程序保护其他段落。本阶段仅按原稿重构，联网增强留待后续。
- 分镜以已确认稿为唯一正文。只移动边界，拼接后字符、标点和顺序完全一致。按有效字50-80字、语义和地点边界切分；例外记录原因。
- 一镜一主要主体，每镜独立路由校园、自然、古迹、城市、街区或转场规则。正文不拼接互不关联的地点，不提前揭晓悬念。
- 9:16满屏写实纪实摄影，四宫格2K源图，每格一独立竖图；8K是风格描述，不是实际分辨率承诺。
- 单独生成封面，允许按全文创意拼接多个地点，不添加创意合成标记；标题由后期排版。
- 封面0.5秒，配音从首帧开始；主副标题只在封面显示；可编辑脚注默认“图片由AI生成”，全片持续。
- 用任务保存的模板快照；不读取国学字体、横图布局或健康视觉默认值。
